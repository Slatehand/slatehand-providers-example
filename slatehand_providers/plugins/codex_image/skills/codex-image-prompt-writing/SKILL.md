# Codex Image 提示词写作

所有参考图的引用顺序与正文对应要求由全局 `slatehand-image-prompt-writing` 统一规定。本 Skill 补充 `codex_image`（GPT Image）在生图（`codex_image.generate`）与改图（`codex_image.edit`）下的模型写作规范。

结构化导演脚本、Keyframe 计划与地点资料已决定本帧的戏剧时刻、可见角色与景别目标；本 Skill 只把已定画面编译成清晰、克制的静态视觉规格，不新增角色、道具、剧情动作或未授权排除项。

## 核心原则：规范胜于堆词

- **总长控制在 ≤ 850 字**：每条 `<PictureN>` 引用说明 ≤ 80 字，画面正文控制在 280–550 字。过长的摄影器材套话与重复修饰会冲淡主体站位、视线和第一视觉重心。
- **画幅不进正文**：画幅由 Core 与插件按项目或请求参数编译传递，正文不重复写比例、像素或“横版/竖版”指令，但构图排布须适配目标画幅。
- **标签严格对齐实际输入**：使用 `<Picture1>`…`<Picture5>`。`codex_image.generate` 最多 5 张参考图并重新组织构图；`codex_image.edit` 的 `<Picture1>` 固定为空间底图（`source_image`），`<Picture2>`…`<Picture5>` 为辅助参考图。

## 有参考图时的正交剥离

每张 `<PictureN>` 开头单独一行，明确“只取什么、剥离什么”，避免把设定图或其它时刻的元素带进当前帧：

- **角色造型设定图**：只取指定人物的五官骨相、发型与当前服装材质；显式剥离设定图的浅灰背景、多视角排版，以及群像设定图里本帧不在场的其他人物（如孩童、随从）或尚未发生的伤妆血迹。
- **地点图与锚点关键帧**：按本帧景别决定继承范围——中近景、特写只取光线色温与局部材质，不继承大景别构图；同时剥离地点图里本帧尚未发生的状态（如未起火时的火海浓烟）与全景透视畸变。

## 生图正文结构（`codex_image.generate`）

空一行后按以下五部分写成紧凑静态描述：

1. **统一媒介与焦段锚点（1 句）**：同一 Scene 保持一致的实拍质感、色调基线与常规焦段（剧本无特殊广角要求时优先 50mm 标准定焦，避免无依据切到 24mm/28mm 超广角造成边缘人脸或马匹拉伸畸变）。
2. **画框与空间层次**：交代景别、机位高度与单一第一视觉重心；次要人群或远景陈设退入后景或浅景深虚化，不与前景主体抢占画框。
3. **主体静态定格**：写明人物裁切范围（如腰部以上）、身体朝向、视线落点及与地面/器物的真实受力接触；首帧只写动作启动前的静止姿态，尾帧只写动作已结束的稳定结果，不写冲撞中途或挥击半途。
4. **光源与阴影**：写明主光方向、色温与落影位置。
5. **单句客观排除（按需）**：确需排除本帧未出现的同卡人物、提前出现的火光血迹或文字水印时，在末尾合并为一句平实排除说明。

### 生图示例

```text
<Picture1>: 身份与服装参考。只取成年男性的五官、束发与深灰粗布短褐；不采用图中的孩童、多视角排版与浅灰底。
<Picture2>: 环境材质与色温参考。只取青砖门洞质感与阴天冷灰天光；不采用图中的火光浓烟与远景构图。

画面正文：
实拍电影静帧，50mm 标准定焦镜头，低饱和冷灰自然色调。平视中近景，成年男性位于画面右侧三分之一处，腰部以上入画，继承<Picture1>的面部特征与深灰粗布短褐。他侧身立于<Picture2>质感的青砖门洞内侧，右手按在闭合的木门栓上，双肩下沉，目光越过门缝望向门外，神情克制紧绷。门洞外远景街道空旷并呈浅景深虚化。阴天漫射冷光自门缝斜照在右侧颧骨与手背，门内暗部保留木纹细节。画面中无孩童、无明火浓烟、无字幕与水印。
```

## 改图正文结构（`codex_image.edit`）

- **机位不变、状态变化**（如同段首尾帧同机位演进）：先写一句保留锚点（“保留 `<Picture1>` 的机位构图、空间陈设、光线方向与人物身份服装”），再集中写变化增量（“仅将人物姿态改为……”），不重复描写未变区域。
- **机位或景别改变**：显式声明“不沿用 `<Picture1>` 的原机位与构图”，写明新机位、景别、遮挡关系与新露出区域，只从 `<Picture1>` 与辅助 `<Picture2+>` 继承身份、服装、道具状态与光线基线。

### 改图示例

```text
<Picture1>: 编辑底图。保留门洞空间、冷灰漫射光及男性的身份与深灰短褐；按正文更新手部与门扇状态。

画面正文：
保留<Picture1>的平视中近景机位、青砖门洞结构、阴天冷灰光线及男性的五官与服装。仅将木门栓改为已拔开垂落，门扇向内拉开一道半尺宽的缝隙；男性左手握住门扇边缘，右手垂于身侧，身体重心后移半步，目光凝视门外地面。其余背景与光影保持不变，无字幕与水印。
```

## 反补丁与修辞禁令

- **不用感叹号与文学修辞**：不写 `!` / `！`、比喻句、心理独白或空泛氛围词，只写镜头此刻拍得到的物理事实。
- **不叠括号结构禁令**：不在句中塞入反复叮嘱肢体完整或不变形的括号否定补丁。候选图出现肢体畸变、透视崩坏或人马粘连时，根因通常是景别过满或姿态落在动作中途——应简化前景人数、收紧景别或退回动作启动前的静止站姿，而不是在原提示词上继续加否定句。
